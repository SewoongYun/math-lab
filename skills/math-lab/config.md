# 내 환경 (설치한 뒤 한 번 채우기)

> math-lab이 시작할 때마다 이 파일을 읽는다. 비워 둔 칸은 오른쪽 기본값으로 동작한다.
> 스킬을 다시 설치하면 이 파일이 덮어써질 수 있으니, 채운 내용은 따로 적어 두자.

## 저장 위치

| 항목 | 내 값 | 비워 두면 |
|---|---|---|
| 노트 폴더 (옵시디언 볼트의 한 폴더 등) | | 노트를 파일로 만들지 않고 대화에 마크다운으로 보여 준다 |
| 책 실험실 HTML 폴더 | | 지금 작업 폴더의 `math-lab 결과/책/` |
| 수능 자료 HTML 폴더 | | 지금 작업 폴더의 `math-lab 결과/수능/` |
| 문제 원문 폴더 (교재 PDF·스캔, 있으면) | | 원문은 사진·텍스트로 받는다 |
| 공부 기록 파일 (표 형식) | | 공부 기록 제안을 하지 않는다 |
| 책 사이트 데이터 파일 (있으면, 예: `data/books.js`) | | 사이트용 항목 초안을 만들지 않는다 |

- 노트 폴더를 정하면 그 안에 `문제 노트/`, `발상 패턴/`, `책 실험실/` 폴더가 생긴다.
- 옵시디언을 쓰면 `[[링크]]`로, 아니면 평범한 마크다운으로 적는다.

| 항목 | 내 값 | 비워 두면 |
|---|---|---|
