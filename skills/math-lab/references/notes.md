# 노트 저장 규칙

## 1. 어디에 저장하나

`config.md`의 **노트 폴더**를 쓴다. 비어 있으면 파일을 만들지 않고, 노트 내용을 마크다운 코드 블록으로 대화에 보여 준다.

| 무엇 | 위치 (노트 폴더 안) | 파일 이름 |
|---|---|---|
| 수능 문제 노트 | `문제 노트/` | `YYYY-MM-DD 출처 짧은제목.md` |
| 발상 패턴 노트 | `발상 패턴/` | `패턴 이름.md` (예: `대칭축으로 두 근 묶기.md`) |
| 책 실험실 기록 | `책 실험실/` | `책 이름.md` (책 한 권에 하나) |

- 폴더가 없으면 만든다 (노트 폴더 안에서만).
- HTML 경로는 노트에 적고, 코드를 노트에 붙여 넣지 않는다.
- 파일 접근이 없는 환경(claude.ai)에서는 "노트 폴더의 ○○에 `파일 이름`으로 저장하세요"라고 알려 준다.

## 2. 양식 (`templates/`)

| 파일 | 쓰임 |
|---|---|
| `templates/problem-note.md` | 수능 문제 하나에 하나. 발상 노트 7문항 + 시뮬레이션·변형 칸 |
| `templates/pattern-note.md` | 발상 패턴 하나에 하나 |
| `templates/book-lab-log.md` | 책 한 권에 하나. 실험실 목록과 손계산 기록 |

- 양식의 `{{date:YYYY-MM-DD}}`는 옵시디언 템플릿용 자리다. 클로드가 직접 만들 때는 오늘 날짜로 바꿔 쓴다.
- 옵시디언을 쓰면 링크는 `[[이름]]`, 아니면 `이름`만 적는다 (`config.md`).

### 문제 노트
- 사용자가 답하는 칸(1~4번, 7번)은 **사용자의 말을 그대로** 적는다. 답하지 않은 칸은 비워 둔다. 클로드가 그럴듯하게 채우지 않는다.
- 클로드의 분석은 "클로드 정리" 칸에 따로 둔다. 누구 생각인지 섞이지 않게.

### 발상 패턴 노트
- 이름은 동사구로 짧게: `치환 후 구간 옮기기`, `여사건으로 세기`, `경계값에서 경우 나누기`.
- 새로 만들기 전에 목록을 보고, 비슷한 게 있으면 그걸 쓴다. 새 이름은 사용자에게 확인한다.
- 문제 노트가 패턴을 링크하면 패턴 노트의 백링크에 문제가 쌓인다 → 나만의 발상 사전.

### 책 실험실 기록
- 실험실을 만들 때마다 표에 한 줄, 손계산은 문제와 사용자의 답을 그대로.

## 3. 공부 기록

- `config.md`에 공부 기록 파일이 있고, 사용자가 시간을 말해 줬을 때만 한 줄 추가한다. 지어내지 않는다.
- 손으로 한 시간만 적는다.

## 4. 지킬 것

- 사용자가 직접 쓴 글의 본문은 허락 없이 고치지 않는다. 링크 한 줄을 덧붙이는 정도만.
- 학생 실명·성적·상담 내용은 저장하지 않는다. 바꿨으면 바꿨다고 말한다.
- 여러 파일을 옮기거나 지우는 일은 먼저 묻는다.
