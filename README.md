# math-lab — 수학 교사를 위한 Claude 스킬

수학책의 한 문장을 **손으로 움직여 보는 실험실**로, 수능 문제를 **이해하고 변형하는 연구**로 바꾸는 Claude 스킬입니다.
`/math-lab` 하나로 두 가지 일을 합니다.

| 모드 | 하는 일 |
|---|---|
| **책 → 실험실** | 밑줄 친 문장 → 숨은 수학 찾기 → 손계산 하나 → 예상·조작·손계산·정리 4~6단계 실험실(HTML) |
| **수능 문제 → 이해·변형** | 이 유형을 푸는 단계, 조건마다 "왜 있나", 시뮬레이션과 경계값 표, 변형 문항(출제 연습 / 수업 자료) |

## 이 스킬이 지키는 것

- **손이 먼저, 예측이 먼저.** 시뮬레이션을 만들기 전에 결과를 예측하고, 실험실을 만들기 전에 계산 하나는 손으로 풉니다.
- **AI가 맡을 일과 교사가 맡을 일을 나눕니다.** AI가 문항 초안을 쓰고 교사가 검토만 하면, 알아보는 능력은 늘어도 만드는 능력은 늘지 않습니다.
  - 출제 연습: 교사가 손으로 초안을 쓰고, Claude는 반례·허점·다른 풀이·검산만
  - 수업 자료: Claude가 세트를 만들되, 검산 표와 "교사가 직접 고칠 1문항"을 붙임
- **원문 없이 분석하지 않습니다.** 문항 번호만 받았는데 원문을 확인할 수 없으면, 문제를 지어내거나 기억으로 풀지 않고 사진이나 텍스트를 요청합니다.
- **검산 표를 남깁니다.** "검산 완료" 한 줄 대신, 무엇을 어떤 방법으로 확인했는지. 수치 검산은 계산 결과를 확인하는 보조 수단일 뿐이라, 경계값·등호·정의역·빠진 경우·논리적 비약은 `논리` 행으로 따로 점검해 적습니다.
- **근거 없는 칭찬을 하지 않습니다.** 잘된 점과 고칠 점을 구체적으로.

## 어디서 쓸 수 있나

이 스킬은 **Claude Code와 claude.ai를 기준으로** 만들었습니다. 파일 구성(`SKILL.md` + frontmatter, `references/`, `scripts/`)은 Agent Skills 형식을 따르지만, **다른 도구에서 동작하는지는 확인하지 않았습니다.**

| 무엇 | 어디서 |
|---|---|
| 흐름과 원칙, 모드별 지침, 노트 양식, HTML 디자인 규칙 | 공통 (환경과 관계없이 같은 내용) |
| `/math-lab …` 슬래시 호출, frontmatter의 `argument-hint`, `~/.claude/skills/` 경로 | Claude Code 전용 |
| 아티팩트로 HTML 보여 주기 | claude.ai 전용 |
| `scripts/numcheck.js` 수치 검산 | Node.js를 실행할 수 있는 환경에서만 |

환경에 따라 저장과 HTML 방식이 이렇게 달라집니다 (`SKILL.md` 0절과 같은 내용).

| 환경 | 노트 | HTML | 수치 검산 |
|---|---|---|---|
| 파일을 읽고 쓸 수 있다 (예: Claude Code) | `config.md`의 노트 폴더에 파일로 | `config.md`의 폴더에 `.html` 파일로 | `numcheck.js` 실행 |
| 파일 접근이 없다 (예: claude.ai 대화창) | 마크다운 코드 블록으로 | 아티팩트 (아티팩트가 없는 도구면 HTML 코드 블록) | 코드 실행이 되면 같은 방식, 안 되면 검산 표에 `실행 못 함` |

## 설치

### Claude Code (터미널, 데스크톱 앱 Code 탭)

```bash
npx skills add SewoongYun/math-lab -g
```

이 명령은 여러 도구에 스킬을 설치할 수 있는 `skills` CLI를 씁니다. 설치할 도구를 묻는 화면이 나오면 Claude Code를 고르세요.
또는 이 저장소의 `skills/math-lab` 폴더를 `~/.claude/skills/math-lab`에 복사합니다. 설치한 뒤 **새 세션**을 열면 `/math-lab`이 보입니다.

### claude.ai 대화창

저장소의 [`math-lab.zip`](https://github.com/SewoongYun/math-lab/raw/main/math-lab.zip)을 받아 **설정 → 기능 → 스킬**에서 올립니다. 이 zip은 claude.ai가 받지 않는 `argument-hint` 줄을 뺀 판입니다.

### 다른 도구

확인하지 않았습니다. Agent Skills 형식을 읽는 도구라면 `skills/math-lab` 폴더를 그 도구의 스킬 폴더에 넣어 볼 수 있지만, 슬래시 호출·아티팩트 같은 Claude 전용 기능은 기대하지 마세요.

### 설치한 뒤 한 번: `config.md` 채우기

`skills/math-lab/config.md`에 노트 폴더(옵시디언 볼트 등), HTML 저장 폴더, 문제 원문 폴더(교재 PDF·스캔, 있으면), 말투를 적습니다. 비워 두면 기본값으로 동작합니다(노트는 대화에 출력, HTML은 지금 폴더의 `math-lab 결과/`).

## 쓰는 법

Claude Code에서는 아래처럼 `/math-lab …`으로 부릅니다. 다른 환경에서는 같은 말을 문장으로 쓰면 됩니다 (예: "math-lab으로 이 문제 변형해 줘").

| 이렇게 쓰면 | 일어나는 일 |
|---|---|
| `/math-lab 책 <책 이름> <쪽>` + 사진 | 문장 확인 → 해부 → 손계산 → 실험실 |
| `/math-lab 수능 <문항 번호>` + 문제 | "풀어 보셨어요?"부터. 힌트는 1→2→3 단계로 |
| `/math-lab 수능 <문항 번호>` (번호만) | 원문부터 확보. 확인할 수 없으면 **문제 사진이나 텍스트를 요청** (아래 2-1) |
| `/math-lab 수능 <번호> 이해` | 이 유형을 푸는 단계, 조건마다 왜 있나, 출제 포인트, 발상의 신호 |
| `/math-lab 수능 <번호> 시뮬` | 예측을 먼저 묻고 시뮬레이터 + 경계값 표 |
| `/math-lab 수능 <번호> 변형` | "출제 연습인가요, 수업 자료인가요?"를 먼저 물음 |
| `/math-lab 검토` + 직접 쓴 변형 문항 | 정답 검산 · 조건 허점 · 반례 · 다른 풀이 · 숫자 · 변형 여부 · 수능 문체 |
| 명령 끝에 `html` | 질문 없이 완성본 HTML (검산 표와 출처는 그대로) |

### 번호만 줬을 때 원문은 어디서 확인하나

1. 이 대화에 이미 있는 문제 사진·텍스트
2. 알려 준 파일, 또는 `config.md`의 문제 원문 폴더 (파일 접근이 되는 환경에서만)
3. 노트 폴더의 같은 번호 문제 노트에 적힌 원문
4. 웹을 열 수 있는 환경이면 공식 출처(평가원 기출은 한국교육과정평가원, EBS 교재는 EBSi). 블로그·커뮤니티에 옮겨 적은 글은 쓰지 않습니다.

넷 다 안 되면 문제를 짐작해 풀지 않고 사진이나 텍스트를 요청합니다. `html`을 붙여도 같습니다. 원문을 확인하면 교재명·연도(학년도)·문항 번호·확인 경로처럼 **확인한 정보만** 출처 줄과 문제 노트에 적습니다.

## 결과 예시

> 아래 세 가지는 **스킬 규칙에 맞춰 직접 쓴 예시**입니다. 실제 실행 결과를 옮긴 것이 아니고, 실제 출력은 대화에 따라 길이와 표현이 달라집니다. 예시의 숫자는 `numcheck.js`와 손계산으로 확인했습니다.

### 예시 1. 책 문장 → 실험실

밑줄 문장 (예시를 위해 지어낸 문장): *"물가가 올랐는지는 가격을 어떻게 평균 내느냐에 따라 달라진다."*

| 단계 | 화면에 나오는 것 |
|---|---|
| 문장 해부 | 숨은 수학: 산술평균과 기하평균 · 학생이 지나치는 이유: "평균은 하나"라는 직관 · 보이게 할 것: 같은 가격 변화에서 두 지수가 갈리는 장면 |
| 손계산 (교사에게 먼저) | "두 물건 값이 각각 ×0.5, ×2가 되었다. 기준 시점 = 100일 때 산술평균 지수와 기하평균 지수는?" → 125, 100 |
| STEP 1 예상 | "두 물건 값이 반값, 두 배가 됐다. 물가는? ① 올랐다 ② 그대로 ③ 내렸다" |
| STEP 2~3 조작 | 슬라이더로 배율 r과 1/r을 바꾸며 두 지수를 막대로 비교. 기록 표에 (r, 산술, 기하) |
| STEP 4 손계산 | 위 숫자로 빈칸 채우기 → 채점 → 풀이 보기 |
| STEP 5 정리 | "산술평균 지수는 r ≠ 1이면 늘 100보다 크다" + STEP 1 예상 다시 보기 + 생각할 거리 Q1~Q5 (하나는 "이런 지수를 보면 무엇을 먼저 확인해야 하나?") |

### 예시 2. 수능 문제 → 이해 · 시뮬레이션

**번호만 줬을 때**

```
나:     /math-lab 수능 <교재명> <문항 번호>
Claude: 그 문항의 원문을 확인할 수 없어요. 문제 사진이나 텍스트를 보내 주시겠어요?
```

**원문을 받은 뒤** (직접 만든 문제: "곡선 $y=x^3-3x$와 직선 $y=k$가 서로 다른 세 점에서 만나도록 하는 정수 $k$의 개수는?")

- 이 유형을 푸는 단계: ① 상수를 분리해 $y=k$와의 교점으로 보기 → ② 미분해 극값 구하기 → ③ 극값 사이에서 교점 3개
- 조건마다 왜 있나: "서로 다른" — 빼면 접할 때(k = ±2)를 셀지 애매해진다
- 경계값 표

  | 매개변수 | 경계값 | 그 전 | 그 후 | 문항 조건으로 쓰면 |
  |---|---|---|---|---|
  | k | −2 | 실근 1개 | 실근 3개 (k = −2에서 2개) | "실근이 3개가 되는 k의 범위" |
  | k | 2 | 실근 3개 | 실근 1개 (k = 2에서 2개) | "서로 다른 실근이 2개인 모든 k의 곱" |

- 검산 표

  | 확인한 것 | 종류 | 방법 | 결과 |
  |---|---|---|---|
  | 정답 3 (k = −1, 0, 1) | 수치 | `countSolutions`로 k = −3…3에서 근의 개수 | k = −1, 0, 1에서만 3개 ✓ |
  | 경계 k = ±2 | 논리 | $f'(x)=3x^2-3=0$ → 극값 $f(-1)=2$, $f(1)=-2$ | 경계 확정 ✓ |
  | k = ±2를 빼야 하나 | 논리 | 접점은 중근 → 서로 다른 점은 2개 | 제외 ✓ |

### 예시 3. 변형 문항 검토 (출제 연습)

교사가 손으로 쓴 초안 (예시): "곡선 $y=x^3-3x$와 직선 $y=k$가 서로 다른 두 점에서 만나도록 하는 모든 실수 $k$의 값의 합은?"

| 항목 | 판정 | 비평 |
|---|---|---|
| (a) 정답 검산 | 괜찮음 | k = 2, −2 → 합 0 |
| (b) 조건 허점 | 괜찮음 | 접할 때만 서로 다른 두 점 → k = ±2 둘뿐 |
| (d) 다른 풀이 | 문제 있음 | 곡선이 원점 대칭이라 계산 없이 "합 0"을 찍을 수 있다 |
| (e) 숫자 | 확인 필요 | 답 0은 단답형 "자연수" 조건에 맞지 않는다 |
| (f) 변형이 됐나 | 괜찮음 | "묻는 것 바꾸기" 축. 원문항의 경계값을 직접 묻게 됐다 |

제안 (최종 문장은 교사가 씀): 곡선을 $y=x^3-3x+5$로 옮기고 "합" 대신 "곱"을 물으면 k = 3, 7 → 답 21. 대칭 지름길이 막히고 답이 자연수가 된다.

| 확인한 것 | 종류 | 방법 | 결과 |
|---|---|---|---|
| 초안의 답 0 | 수치 | `countSolutions`로 k = ±2에서 근 2개 | ✓ |
| 초안에서 두 점이 되는 k가 ±2뿐인가 | 논리 | 극값 ±2 사이면 3개, 밖이면 1개 | 빠진 경우 없음 ✓ |
| 제안의 k = 3, 7 | 수치 | `solveParam`으로 근이 2개가 되는 k 찾기 | 약 3.005, 7.005 (근삿값) |
| 제안의 k = 3, 7이 정확한 값인가 | 논리 | 극값 $f(\pm1)=5\mp2$를 직접 구함 | 3, 7 확정 ✓ |

## 들어 있는 것

```
skills/math-lab/
├─ SKILL.md              흐름과 원칙
├─ config.md             내 환경 (설치 후 채우기)
├─ references/
│  ├─ book-mode.md       책 → 실험실
│  ├─ csat-mode.md       수능 문제 → 원문 확보·이해·시뮬레이션·변형
│  ├─ sim-design.md      HTML 디자인·정확성 규칙
│  └─ notes.md           노트 저장 규칙
├─ templates/            문제 노트 · 발상 패턴 · 책 실험실 기록 양식 (옵시디언 템플릿으로도 사용)
└─ scripts/numcheck.js   수치 검산 도구 (Node.js) — 최댓값·최솟값, 근 찾기(접하는 근 포함), 적분, √·π 꼴 후보
```

`numcheck.js`는 부동소수로 근삿값을 계산하는 확인 도구입니다. 증명하지 않고, 훑은 구간 밖·열린구간·등호 조건·불연속점은 판정하지 못합니다. 할 수 있는 것과 없는 것은 파일 첫머리에 적혀 있습니다.
