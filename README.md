# math-lab — 수학 교사를 위한 Claude 스킬

수학책의 한 문장을 **손으로 움직여 보는 실험실**로, 수능 문제를 **이해하고 변형하는 연구**로 바꾸는 Claude 스킬입니다.
`/math-lab` 하나로 두 가지 일을 합니다.

| 모드 | 하는 일 |
|---|---|
| **책 → 실험실** | 밑줄 친 문장 → 숨은 수학 찾기 → 손계산 하나 → 예상·조작·손계산·정리 4~6단계 실험실(HTML) |
| **수능 문제 → 이해·변형** | 이 유형을 푸는 단계, 조건마다 "왜 있나", 시뮬레이션과 경계값 표, 변형 문항(출제 연습 / 수업 자료) |

## 이 스킬이 지키는 것

- **손이 먼저, 예측이 먼저.** 시뮬레이션을 만들기 전에 결과를 예측하고, 실험실을 만들기 전에 계산 하나는 손으로 풉니다.
- **AI가 맡을 일과 교사가 맡을 일을 나눕니다.** AI가 문항 초안을 쓰고 교사가 검토만 하면, 알아보는 능력은 늘어도 만드는 능력은 늘지 않습니다.
  - 출제 연습: 교사가 손으로 초안을 쓰고, Claude는 반례·허점·다른 풀이·검산만
  - 수업 자료: Claude가 세트를 만들되, 검산 표와 "교사가 직접 고칠 1문항"을 붙임
- **검산 표를 남깁니다.** "검산 완료" 한 줄 대신, 무엇을 어떤 방법으로 확인했는지.
- **근거 없는 칭찬을 하지 않습니다.** 잘된 점과 고칠 점을 구체적으로.

## 설치

### Claude Code (터미널, 데스크톱 앱 Code 탭)

```bash
npx skills add SewoongYun/math-lab -g
```

또는 이 저장소의 `skills/math-lab` 폴더를 `~/.claude/skills/math-lab`에 복사합니다. 설치한 뒤 **새 세션**을 열면 `/math-lab`이 보입니다.

### claude.ai 대화창

저장소의 [`math-lab.zip`](https://github.com/SewoongYun/math-lab/raw/main/math-lab.zip)을 받아 **설정 → 기능 → 스킬**에서 올립니다.

### 설치한 뒤 한 번: `config.md` 채우기

`skills/math-lab/config.md`에 노트 폴더(옵시디언 볼트 등), HTML 저장 폴더, 말투를 적습니다. 비워 두면 기본값으로 동작합니다(노트는 대화에 출력, HTML은 지금 폴더의 `math-lab 결과/`).

## 쓰는 법

| 이렇게 쓰면 | 일어나는 일 |
|---|---|
| `/math-lab 책 <책 이름> <쪽>` + 사진 | 문장 확인 → 해부 → 손계산 → 실험실 |
| `/math-lab 수능 <문항 번호>` + 문제 | "풀어 보셨어요?"부터. 힌트는 1→2→3 단계로 |
| `/math-lab 수능 <번호> 이해` | 이 유형을 푸는 단계, 조건마다 왜 있나, 출제 포인트, 발상의 신호 |
| `/math-lab 수능 <번호> 시뮬` | 예측을 먼저 묻고 시뮬레이터 + 경계값 표 |
| `/math-lab 수능 <번호> 변형` | "출제 연습인가요, 수업 자료인가요?"를 먼저 물음 |
| `/math-lab 검토` + 직접 쓴 변형 문항 | 정답 검산 · 조건 허점 · 반례 · 다른 풀이 · 숫자 · 변형 여부 · 수능 문체 |
| 명령 끝에 `html` | 질문 없이 완성본 HTML (검산 표와 출처는 그대로) |

## 들어 있는 것

```
skills/math-lab/
├─ SKILL.md              흐름과 원칙
├─ config.md             내 환경 (설치 후 채우기)
├─ references/
│  ├─ book-mode.md       책 → 실험실
│  ├─ csat-mode.md       수능 문제 → 이해·시뮬레이션·변형
│  ├─ sim-design.md      HTML 디자인·정확성 규칙
│  └─ notes.md           노트 저장 규칙
├─ templates/            문제 노트 · 발상 패턴 · 책 실험실 기록 양식 (옵시디언 템플릿으로도 사용)
└─ scripts/numcheck.js   수치 검산 도구 (최댓값·최솟값, 접점 포함 근의 개수, √·π 꼴 알아보기)
```
